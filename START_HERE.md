## 🚀 30-Minute Quick Start

### Phase 1: Setup Supabase (10 min)
```
1. Go to supabase.com → Create project
2. Copy SUPABASE_SETUP.sql file contents
3. In Supabase → SQL Editor → Paste → RUN
4. Go to Settings → API → Copy URL & key
```

### Phase 2: Configure App (5 min)
```
1. Create file: .env (in project root)
2. Add 5 variables (see .env.example)
3. Update with your Supabase credentials
4. Set school GPS coordinates
```

### Phase 3: Run App (5 min)
```
npm install
npm run start
```

### Phase 4: Test (10 min)
- Press "a" for Android emulator
- Wait 30 seconds for app to load
- Login with: principal@demo.com / Password123!
- Test features and verify

## 🆘 Troubleshooting Quick Links

- **"npm: command not found"** → Install Node.js first
- **"Module not found"** → Run `npm install`
- **"Connection refused"** → Check .env file
- **"Can't log in"** → Create test user in Supabase Auth
- **"Geofence not working"** → Enable GPS on emulator
- **"App won't start"** → Run `npm start -- --clear`

See `QUICK_START.md` for complete troubleshooting.
